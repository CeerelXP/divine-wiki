## .bin: Dados e lógica

Arquivos `.bin` armazenam **toda a lógica** do League: sistemas de partículas, definições de skins, animações, sons e muito mais.

| Contém           | Exemplos                    |
| ---------------- | -------------------------- |
| Dados de partículas | cores, tamanho, timing   |
| Definições de skin | caminhos de modelo e textura |
| Config de animação | nomes e blending          |
| Config de som     | triggers de áudio e volume |

### Fluxo de trabalho

1. Extrair `.bin` usando [Flint](/docs/lol/tools/modding-apps/flint)
2. Converter para `.py` usando [Ritobin](/docs/lol/tools/modding-apps/ritobin) (ou editar direto no [Jade](/docs/lol/tools/modding-apps/jade))
3. Editar em um editor de texto como VS Code ou Notepad++
4. Converter de volta para `.bin`
5. Adicionar ao mod

> 💡 Arquivos `.py` são legíveis. Dá para pesquisar e editar facilmente.

## .dds: Texturas

`.dds` (DirectDraw Surface) é o **formato padrão de texturas** usado para:

| Uso            | Exemplos                  |
| -------------- | ------------------------ |
| Modelos de campeão | skins, rostos         |
| Partículas     | sprites de VFX, brilhos |
| UI/HUD         | ícones e painéis        |

### Ferramentas de edição

<ToolCard name="Photoshop" href="https://www.adobe.com/products/photoshop.html">
  Melhor opção com plugin DDS da NVIDIA.
</ToolCard>

<ToolCard name="GIMP" href="https://www.gimp.org/">
  Alternativa gratuita com suporte a DDS.
</ToolCard>

<ToolCard name="Paint.NET" href="https://www.getpaint.net/">
  Leve e com plugin DDS.
</ToolCard>

### Configurações de exportação

| Configuração | Valor         |
| ------------ | ------------- |
| Formato      | `.dds`        |
| Compressão   | **BC3 / DXT5** |
| Mipmaps      | ✅ Ativado     |

> ⚠️ Compressão errada = textura quebrada no jogo!

## .tex: Formato da Riot

`.tex` é o formato proprietário da Riot encontrado em arquivos `.wad.client`.

| Status                | Informação                 |
| --------------------- | -------------------------- |
| ❌ Não edita direto   | É um formato compilado     |
| ✅ Precisa converter  | Usar tex2dds              |
| ✅ Converter de volta | Antes de reimportar        |

Você tem duas formas de trabalhar com `.tex`:

1. Abrir diretamente com um plugin TEX no seu editor de imagem. Sem conversão.
2. Converter `.tex` ↔ `.dds` usando Flint ou LtMAO.

<ToolCard

<ToolCard

> 💡 Sempre mantenha o `.tex` original como backup antes de converter.

## Fluxo completo

| Tarefa               | Arquivo | Ferramenta                         | Saída           |
| -------------------- | ------- | ---------------------------------- | --------------- |
| Editar VFX/partículas | `.bin`  | Jade (ou Ritobin)                  | `.bin`          |
| Editar skin          | `.dds`  | Photoshop/GIMP                     | `.dds`          |
| Editar textura direto | `.tex`  | RitoTex, Paint.NET ou GIMP plugin | `.tex`          |
| Converter textura    | `.tex`  | Flint ou LtMAO                    | `.dds`          |
| Reimportar textura   | `.dds`  | Flint ou LtMAO                    | `.tex`          |
| Explorar arquivos do jogo | `.wad` | Flint                          | arquivos extraídos |
