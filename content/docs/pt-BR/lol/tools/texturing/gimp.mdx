O GIMP é um editor de imagens gratuito e open-source, o mais próximo de um Photoshop gratuito. Para modding de League of Legends, instale o [Gimp Tex Plugin](/docs/lol/tools/texturing/gimp-tex-plugin) para conseguir abrir arquivos `.tex` diretamente.

[Baixar GIMP](https://www.gimp.org/downloads/)

---

## Para que você vai usar

- Editar splash arts de campeões e telas de carregamento.
- Modificar ou criar texturas personalizadas.
- Trabalhar com arquivos `.dds` e `.tex` (com plugins).
- Criar PNGs transparentes para elementos de interface.

O GIMP lida apenas com trabalho 2D. Para modelos 3D, use
[Maya](/docs/lol/tools/3d-modeling/maya) ou [Blender](/docs/lol/tools/3d-modeling/blender).
