O **LTK Tex Thumb Handler** é uma extensão de shell do Windows da equipe **LeagueToolkit**. Ele exibe arquivos `.tex` como pré-visualizações de imagem no Windows Explorer.

Ele faz a mesma função que o [Tex Thumbnail Provider](/docs/lol/tools/texturing/tex-thumbnail-provider), do RitoShark. Escolha apenas um dos dois.

[Baixar a versão mais recente](https://github.com/LeagueToolkit/ltk-tex-utils/releases)

---

## O que ele faz

- Mostra arquivos `.tex` como miniaturas (thumbnails) no Windows Explorer.
- Funciona em qualquer pasta com texturas `.tex` (arquivos do jogo, exports, mods).
- Funciona como uma DLL COM registrada. Não há aplicativo para abrir. Não roda em segundo plano.

{/* SCREENSHOT: Windows Explorer mostrando arquivos .tex com miniaturas de imagem em vez de ícones genéricos */}

---

## Antes de começar

- Windows 10 ou 11.
- Acesso de administrador (o instalador registra uma DLL no sistema).
- PowerShell.

---

## Instalação

1. Feche qualquer janela do Windows Explorer que esteja exibindo arquivos `.tex`.
2. Clique com o botão direito no PowerShell e escolha **Executar como administrador**.
3. Cole o seguinte comando e pressione Enter:

   ```powershell
   iwr -useb https://raw.githubusercontent.com/LeagueToolkit/ltk-tex-utils/main/scripts/install-thumbnail-handler.ps1 | iex
   ```

4. Espere o instalador terminar. Ele baixa o `ltk-tex-thumb-handler.dll`,
   copia para `%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler` e
   registra no Windows.
5. Reinicie o Windows Explorer (ou reinicie o PC).

{/* SCREENSHOT: PowerShell window showing the install script output with success message */}

---

## Como saber se funcionou

Abra qualquer pasta com arquivos `.tex`. Os ícones viram pré-visualizações de imagem. Se
eles ainda parecerem ícones em branco, reinicie o Explorer ou o PC.

---

## Desinstalação

1. Clique com o botão direito no PowerShell e escolha **Executar como administrador**.
2. Execute:

   ```powershell
   regsvr32.exe /u "%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler\ltk_tex_thumb_handler.dll"
   ```

3. Apague a pasta em `%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler`.

---

## Quando usar este ou o Tex Thumbnail Provider

As duas ferramentas fazem a mesma coisa: mostram pré-visualizações `.tex` no Explorer. Use apenas
uma por vez.

| Ferramenta                 | Feito por     | Método de instalação            |
| -------------------------- | ------------- | ------------------------------- |
| **LTK Tex Thumb Handler**  | LeagueToolkit | Comando único no PowerShell (admin)    |
| **Tex Thumbnail Provider** | RitoShark     | Comando único no PowerShell (por usuário) |

Escolha o LTK Tex Thumb Handler se você já usa outras ferramentas do LeagueToolkit.
Escolha a versão do RitoShark se quiser uma instalação por usuário, sem direitos de administrador.

> **Aviso.** Não instale as duas. Dois manipuladores de miniaturas para o mesmo
> tipo de arquivo podem entrar em conflito e deixar você sem nenhuma pré-visualização.
> Desinstale um antes de instalar o outro.

## Solução de problemas

### As miniaturas não aparecem

Reinicie o Windows Explorer. Abra o Gerenciador de Tarefas, encontre o **Windows Explorer**,
clique com o botão direito e escolha **Reiniciar**. Abra a pasta de novo.

### Ainda sem miniaturas depois de reiniciar

Verifique se a DLL está em
`%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler\ltk_tex_thumb_handler.dll`.
Se ela estiver faltando, execute o comando de instalação de novo.

### A DLL antiga do Tex Thumbnail Provider ainda está registrada

Desinstale primeiro o outro manipulador de miniaturas. Veja a
[página do Tex Thumbnail Provider](/docs/lol/tools/texturing/tex-thumbnail-provider)
para os passos de instalação e remoção.

### O script de instalação falha

Garanta que o PowerShell está rodando como administrador. O script precisa de direitos de
administrador para registrar a DLL no Windows.
