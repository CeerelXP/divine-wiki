O Paint.NET é um editor de imagens leve e gratuito para Windows. É a opção mais simples para trabalhar com texturas de League of Legends se Photoshop e GIMP parecerem exagerados. Para modding de League, instale o [Paint.NET Tex Plugin](/docs/lol/tools/texturing/paint-net-tex-plugin) para que ele consiga abrir arquivos `.tex` diretamente.

[Baixar Paint.NET](https://www.getpaint.net/download.html)

---

## Para que você vai usar

- Editar splashes de campeões e telas de carregamento.
- Modificar ou criar texturas personalizadas.
- Trabalhar com arquivos `.tex` (com o plugin).
- Criar PNGs transparentes para elementos de UI.

O Paint.NET lida apenas com trabalho de imagem 2D. Para modelos 3D, use
[Maya](/docs/lol/tools/3d-modeling/maya) ou [Blender](/docs/lol/tools/3d-modeling/blender).
