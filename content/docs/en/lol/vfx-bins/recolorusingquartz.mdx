How to recolor vfx using quartz


First select the painbrush tool then open bin <img src="/wiki-images/uno.png" alt="" />


After the bin loads, you should be greeted with a menu, You may not understand what some mean

Heres a small cheat sheet to explain how to search up abilities 



 _ Q _ For q vfx
 _ W _ for W vfx
 _ E _ for e vfx
 _ r _ for r vfx
 _ Ba_ for basic attack vfx
_ Z _ For idle vfx



<img src="/wiki-images/dos.png" alt="" />

You can select the color you want using the color slider on the top, if one isnt enough you can select more using the slider 


<img src="/wiki-images/tres.png" alt="" />



After selecting the vfx u would like to recolor, Press recolor selected and then save



Either test out ingame or in ruby the application (ruby is easier)

And there you go! no more hacksaw!
