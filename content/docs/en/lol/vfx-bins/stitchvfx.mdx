<PremiumCard title="HOW TO STICH VFX (aka steal from other skins/champs) USING QUARTZ" href="/docs/category/slug">
  This tutorial requires 
    Quartz, make sure you already have it installed 
    https://github.com/RitoShark/Quartz
</PremiumCard>


First of all, Open quartz and navigate to the Port Tab in the home screen
<img src="/wiki-images/quartzre-2.png" alt="" />


<img src="/wiki-images/dedxc.png" alt="" />


Open Your vfx Bin, Usually In the data folder


<img src="/wiki-images/cxvcvx.png" alt="" />

Click the Game controller icon to Open Donor bins, those bins include the ingame skins/champs



<Callout type="info" title="CHEAT SHEET">
  Mis= Missle(what the champ throws)
  Tar= Target(what happens when the effect hits someone)
</Callout>


After you find the effects u wanna port over, Select your target effect and then click the Arrow on the source effect to port it over 


And thats it
